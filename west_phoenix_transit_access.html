Transportation GIS

West Phoenix Transit Accessibility Gaps Dashboard

Phoenix, Arizona

This project identifies potential transit-access gaps in West Phoenix by comparing household vehicle availability with proximity to public transit. Census block groups with more than 15% of households lacking a vehicle were evaluated against a 0.25-mile transit access area, then mapped in an ArcGIS Dashboard to highlight higher-need locations.

View Interactive Dashboard Back to Projects

Project Goal

The goal was to identify census block groups where limited household vehicle access coincides with weaker nearby transit access. Areas were treated as higher need when more than 15% of households reported no vehicle and the block group fell outside the selected 0.25-mile transit access area.

GIS Methods

  • Prepared U.S. Census block group geography for the West Phoenix study area.
  • Joined 2024 ACS vehicle availability data and calculated the percentage of households without access to a vehicle.
  • Separated block groups with null ACS values so missing data would not be interpreted as zero vehicle need.
  • Combined Valley Metro transit stop data and created a 0.25-mile buffer to represent nearby transit access.
  • Identified higher-need block groups where more than 15% of households lacked a vehicle and the area was outside the 0.25-mile transit access zone.
  • Exported the qualifying areas as a Transit Deserts layer, then published the results to ArcGIS Online and configured an interactive dashboard.

Data Sources

  • U.S. Census Bureau 2024 ACS vehicle availability data
  • U.S. Census Bureau TIGER/Line block group geography
  • Valley Metro transit stop data
  • Esri basemap and ArcGIS Online web mapping tools

Skills Demonstrated

ArcGIS Pro ArcGIS Online ArcGIS Dashboards Transit Access Analysis Buffer Analysis Spatial Joins ACS Data Data Cleaning Web Map Publishing

Key Takeaway

The analysis narrows a broad transit-access question into a clear screening rule: areas with relatively high no-vehicle households and no transit stop within the selected 0.25-mile access threshold receive greater planning attention. GIS made it possible to combine demographic need and transit proximity into one mapped decision-support layer.

Limitations

This analysis uses proximity to bus stops as a basic measure of access and does not fully account for route frequency, service hours, sidewalk quality, travel time, safety, or actual rider experience. The dashboard should be interpreted as a screening tool for identifying areas that may deserve closer transportation planning review.
