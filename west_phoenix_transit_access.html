Transportation GIS

West Phoenix Transit Accessibility Gaps Dashboard

Phoenix, Arizona

This project identifies high-need areas in West Phoenix where limited household vehicle access overlaps with weaker nearby transit access. The final dashboard highlights block groups where transportation disadvantage may require additional planning attention.

View Interactive Dashboard Back to Projects

Project Goal

The goal of this project was to locate census block groups where residents may face higher transportation vulnerability due to limited vehicle access and weaker proximity to bus stops. The dashboard presents these areas in a clear format for planning and communication.

GIS Methods

  • Prepared census block group data for the West Phoenix study area.
  • Used ACS vehicle availability data to identify areas with higher no-vehicle households.
  • Created transit access buffers around bus stop locations.
  • Identified block groups outside the selected transit access distance.
  • Intersected high no-vehicle areas with weaker transit access areas.
  • Published the results to ArcGIS Online and configured an interactive dashboard.

Data Sources

  • U.S. Census Bureau ACS vehicle availability data
  • Census block group geography
  • Valley Metro bus stop data
  • City / regional GIS reference layers
  • Esri basemap and ArcGIS Online web mapping tools

Skills Demonstrated

ArcGIS Pro ArcGIS Online ArcGIS Dashboards Transit Access Analysis Buffer Analysis Spatial Joins ACS Data Data Cleaning Web Map Publishing

Key Takeaway

Transit access gaps are most important when they overlap with households that may rely more heavily on public transportation. This project shows how GIS can identify places where transportation access, household need, and planning priorities intersect.

Limitations

This analysis uses proximity to bus stops as a basic measure of access and does not fully account for route frequency, service hours, sidewalk quality, travel time, safety, or actual rider experience. The dashboard should be interpreted as a screening tool for identifying areas that may deserve closer transportation planning review.
